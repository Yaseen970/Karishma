Shaik Karishma - React Portfolio (Vite)

Requires Node.js 18+ (https://nodejs.org)
1. Open this folder in VS Code (File > Open Folder)
2. Terminal > New Terminal, then run:
     npm install
     npm run dev
3. Open the link it prints (http://localhost:5173)

Edit content in src/data.js, sections in src/components/, styles in src/style.css.
Build for hosting: npm run build  (output goes to the dist folder)
